# 王津银：传统企业 Agentic 转型

**来源：** 王津银会议分享，2026-03-16

## 一、认知重构

### 1. 从工具思维转向 Agentic 思维
- 摒弃"AI补丁"模式：反对将 AI 作为工具嵌入现有系统（如 Workflow 编排），指出这如同"皮卡车载无人机"，无法发挥 AI 的真正价值
- 确立 Agentic Enterprise 方向：主张将 AI 视为"近似人工"的伙伴（Human-like），致力于打造智能体驱动的企业，而非仅提供零散的工具
- 拒绝场景化误区：批评了单纯基于现有场景进行 AI 改造的思路，指出这会导致"公司体感无变化"，必须重构业务流程本身

### 2. 组织架构的颠覆性重塑
- 推行"三人行"小团队模式：强制拆解传统职能型组织，将团队规模控制在 3-5 人，以减少沟通成本和人为主导，让 AI 介入核心业务流
- 扁平化与去层级化：废除传统的售前、交付、售后等冗长链路，要求内部交易链路不超过两层，实现业务闭环
- 构建 Agent OS 与生产力平台：打造统一的 AI 能力承接平台（如贾维斯），将所有员工工作界面统一于此，实现上下文管理与能力沉淀

## 二、转型实践的关键策略与落地

### 1. 激励机制与 Token 经济学
- Token 作为核心度量指标：将 Token 消耗量与员工产出结果强关联，作为衡量 AI 使用效能和意愿的关键指标，并建议纳入绩效考核
- 构建超级个体：通过 AI 赋能，目标是实现个体生产力的十倍提升，推动员工从执行者转变为构建者（Builder）

### 2. 研发与交付模式的变革
- 从 AI Coding 到 Agent Engineering：研发模式不再依赖传统的工时制评估（如敏捷、Jira），转向基于 Agent 技能（Skill）的快速迭代
- 重构客户交付体验：利用 Agent 能力，实现从客户需求输入到方案输出的端到端自动化，大幅缩短交付周期

## 三、转型过程中的挑战与应对

### 1. 团队认知与思维的刷新
- 破除思维定式：强调必须抛弃过去的软件工程经验（如 DevOps、微服务），重新认知 AI 作为新物种的特性
- 推行"吃狗粮"策略：强制员工使用 AI 工具（如 Cursor、Copilot），通过内部 Aha Moment 分享会刷新认知

### 2. 管理层与团队的博弈
- 自上而下与自下而上结合：转型必须由 CEO/CTO 强力推动，同时需要识别并扶持团队内部的"星火"试点人员
- 化解员工抵触情绪：面对"AI抢饭碗"的恐慌，需通过明确的激励机制和成果导向，证明 AI 是赋能而非替代

## 四、QA 环节

### Q1: 关于转型主导与落地节奏
- **提问人** Gpt：老板想主推转型，但公司内部是旧有建制且缺乏 AI Native 思维。作为新人空降主导转型，会面临哪些问题及如何应对？
- **回答人** 王津银：面临老板对降本增效的急切期望及员工的自我保护机制（担心被裁员）。解决方案是高频沟通刷新老板认知，同时在团队内部寻找有转型意愿且有动手能力的"星火"成员组建试点团队，优先选择人员最多的业务部门进行改造以快速见效。

### Q2: 关于 Agent 产品的具体形态
- **提问人** 陈瑞康：目前在国企做流程自动化（如 Excel 表格处理），但缺乏自然语言交互能力。想了解王总的 Agent 产品具体是什么形态？
- **回答人** 王津银：当前的自动化仅是加速开发，并未体现真正的 AI 能力。建议将视角从单一动作（如排班）提升到端到端的业务流闭环，反向抽象成 Agent Team（多个角色协作），通过 Agent Skill 来实现更高级的智能化。

### Q3: 关于 Agent 落地的前置条件
- **提问人** 大史：在团队内部落地 Agent 赋能，是否必须要有靠谱的 Benchmark（基准测试）？
- **回答人** 王津银：不一定。在传统组织中，IT 部门很难对强势的业务部门进行 Benchmark。关键在于 IT 部门要通过 3 个月的时间自证能力，证明 AI 能帮助业务部门扩大产能，以此获得话语权。
